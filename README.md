# Online Food Ordering System

## Description
This is a Python-based Online Food Ordering System.

## Features
- Food Menu
- Quantity Selection
- 10% Discount
- 5% GST
- Coupon Code (SAVE50)
- Payment Method
- Order History
- Order Receipt

## Technologies Used
- Python
- File Handling
- GitHub
## How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Make sure Python is installed.
4. Run:
   python main.py
